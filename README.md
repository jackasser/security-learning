# ITセキュリティ学習サイト（試作）

架空のシステムを操作して攻撃を体験し、どの対策で止まるかを自分で確かめる教材です。ITの専門家でない人に向けて作っています。

## 使い方
ダウンロードして `index.html` をブラウザで開きます。ログインは要りません。外部との通信も、入力の保存もしません。

| 話 | 学ぶこと |
|---|---|
| 1 退職者アカウントからの情報漏えい | 見てよい人かを、サーバーで確かめる |
| 2 ログインなしで読める予約データ | データベースに、誰がどの行を使えるかの決まりを入れる |

## 注意
会社、人、データ、アドレスはすべて架空です。許可のない実在のシステムで同じことを試さないでください。法律に触れるおそれがあります。

試作段階です。専門家でない読者による試用は、まだ終えていません。
